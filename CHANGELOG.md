## Versioning

Khethi in Tech will use semantic versioning where applicable:

`MAJOR.MINOR.PATCH`

### MAJOR

Significant changes that may fundamentally alter the platform.

### MINOR

New functionality that does not break existing functionality.

### PATCH

Bug fixes, corrections, improvements, and minor changes.

---

## Changelog Guidelines

Changes should be added under the appropriate category.

### Added

New functionality, pages, components, resources, or features.

### Changed

Changes to existing functionality or design.

### Deprecated

Features that are still available but are planned for removal.

### Removed

Features that have been removed.

### Fixed

Bug fixes and corrections.

### Security

Security-related changes.

Changelog entries should describe meaningful changes from the user's or project's perspective rather than documenting every individual Git commit.
