Learn

Find a path into technology.

You do not need to learn everything at once. Pick one direction, work through the fundamentals, then practise by making something small.

Start here

Web development

Learn how the web is structured, styled and made interactive. Build small pages as you go.

  1. HTML structure and accessibility basics
  2. CSS layout and responsive design
  3. JavaScript fundamentals and browser APIs
  4. Version control and publishing a small site

Software engineering

Strengthen problem solving and the habits that help projects stay understandable.

  1. Practise one programming language consistently
  2. Learn Git and the command line
  3. Break a problem into smaller parts
  4. Test, document and revise your work

Explore data

Data engineering

Start with programming, SQL and data modelling before exploring larger pipelines.

  1. Practise Python basics
  2. Learn relational data and SQL
  3. Work with files and simple transformations
  4. Study reliability, privacy and data quality

Think securely

Cybersecurity

Build a foundation in safe computing, threat awareness and secure development habits.

  1. Learn networking and operating system basics
  2. Practise account and device security
  3. Understand common web application risks
  4. Use legal, guided practice environments

A study loop that works anywhere

Learn a concept. Use it. Explain it.

Set a small goal, use a trusted reference, make a tiny project and write down what surprised you. Repeat before adding another tool or course.
