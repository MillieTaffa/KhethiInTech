Learning pathways · career first

Choose a career path. Learn the tools.

Start with the kind of work you want to do. Each pathway shows the skills behind the role, a free-first learning route and a small project to prove what you can do.

The roles below reflect global growth forecasts and South African occupations named on the 2024 high-demand list. Demand changes by place and experience. Read the research and career guide.

Global growth · South African high-demand list

Software and application developer

Build and maintain websites, applications, APIs and the tests that keep them from doing a dramatic backflip in production.

Build these skills

  • One language such as JavaScript, Python or Java
  • Git, data structures, testing and SQL basics
  • Accessible interfaces, APIs and clear documentation

Free-first learning route

  1. CS50x for computing and programming foundations
  2. freeCodeCamp or The Odin Project for guided web projects
  3. MDN and Pro Git for references

Portfolio proof: publish a useful responsive app with tests and a readable README.

Global growth · South African high-demand list

Data analyst or data engineer

Analysts turn questions into evidence. Engineers make the pipelines and databases that deliver clean, trustworthy data.

Build these skills

  • SQL, Python, spreadsheets and data modelling
  • Cleaning, validation and simple statistics
  • Dashboards and explaining uncertainty

Free-first learning route

  1. MIT's Python course or Saylor CS101
  2. SQLBolt, then PostgreSQL
  3. IBM SkillsBuild and pandas

Portfolio proof: analyse a public dataset, show your cleaning steps and explain one useful finding.

Fast-growing global role family

AI and machine learning specialist

Prepare data, build or evaluate models, and make sure automated systems are useful, tested and responsibly applied.

Build these skills

  • Python, statistics and data preparation
  • Model evaluation, experiments and software basics
  • Privacy, bias and responsible AI practice

Free-first learning route

  1. Build programming foundations with CS50x
  2. Practise with Kaggle Learn and Google Cloud's AI introduction
  3. Take IBM SkillsBuild modules that match your goal

Portfolio proof: compare a small model's predictions with a simple baseline and explain its mistakes.

Fast-growing global role family

FinTech software engineer

Build software for payments, banking, lending and financial data. The work rewards careful thinking because a tiny bug can make a very confusing spreadsheet become everyone's problem.

Build these skills

  • Programming, APIs, SQL and reliable data handling
  • Authentication, privacy, testing and secure coding
  • Care with financial rules, edge cases and audit trails

Free-first learning route

  1. CS50x for programming foundations
  2. SQLBolt and OpenAPI for data and APIs
  3. OWASP's Top 10 for secure application basics

Portfolio proof: build a sample budgeting or payment-tracking app with fictional data. Never store real banking details.

Global growth · South African high-demand list

Cybersecurity or ICT security specialist

Help organisations understand risk, monitor systems, investigate issues and fix security weaknesses with permission.

Build these skills

  • Networking, Linux, Windows and basic scripting
  • Identity, logs, web security and safe testing
  • Clear reports that describe impact and remediation

Free-first learning route

  1. Harvard's Introduction to Cybersecurity or Cisco Networking Academy
  2. TryHackMe's free rooms and OverTheWire
  3. PortSwigger Web Security Academy for guided web labs

Portfolio proof: document a finding in a legal training lab and include clear remediation steps.

Cross-industry technical work

Cloud, platform or DevOps engineer

Automate software delivery and help applications stay available, observable, secure and within budget.

Build these skills

  • Linux, networking, Git and scripting
  • Containers, cloud services and deployment pipelines
  • Monitoring, backups, security and cost controls

Free-first learning route

  1. Linux Journey and Docker Get Started
  2. GitHub Actions for simple automation
  3. Microsoft Learn or IBM SkillsBuild

Portfolio proof: deploy a small app and document how to monitor, secure and switch it off.

South African high-demand list

ICT systems analyst

Connect user needs and technical systems. Understand a process, write requirements and help a team choose a workable solution.

Build these skills

  • Systems thinking, APIs, databases and process mapping
  • Requirements, testing, privacy and documentation
  • Interviewing users and explaining technical choices

Free-first learning route

  1. CS50x for core computing concepts
  2. OpenAPI and Google Technical Writing
  3. IBM SkillsBuild for role-relevant topics

Portfolio proof: map a real process with permission, prototype an improvement and document what changed.

Keep your budget intact

Free lessons first. Pay only for a clear reason.

Most learning paths can begin with free courses and official documentation. Certificates, exams, premium labs and some full course tracks may cost money. Check the exact terms before you sign up, and build a project alongside every course.
