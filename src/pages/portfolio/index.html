Cybersecurity · portfolio project

SentinelScanner

A modular cybersecurity assessment and threat detection project built around a Detect, Explain, Remediate and Verify workflow. It explores phishing URL pattern detection, controlled SQL injection testing in a local lab, security configuration checks, findings management and reporting.

Tools: Python, SQLite, Streamlit, Plotly, pytest, Docker and Linux.

What it demonstrates: breaking security checks into modules, classifying and presenting findings, testing behaviour, and connecting detection to clear remediation steps.

Data engineering · portfolio project

SocialPulse

A data project exploring social media engagement metrics such as views, likes, comments and shares. The workflow prepares structured data, uses SQL and Python, and presents patterns in an interactive dashboard.

Tools: Python, pandas, SQL, PostgreSQL, Streamlit and data visualisation.

Project goal: make engagement data easier to process, explore and interpret, while practising the path from raw data to a useful view.
