Build note · Khethi in Tech

Making KIT a home for more than one kind of work

Khethi in Tech started with a Plug Hub page, but the idea behind the name is wider: a personal technology platform that can hold a portfolio, learning resources and selected opportunities together.

That meant the first useful step was to give those parts a shared home. The site now uses one visual system, consistent navigation, a persistent theme choice and search that can point people across the sections.

The project is intentionally built with HTML, CSS and JavaScript. A static site keeps publishing simple while the content is still growing. It also means there is no account system, database, payment flow or live opportunity feed behind the pages.

The next work is content: adding real projects, practical notes and opportunities only when their source and terms can be checked. The platform should grow from things that are actually useful, rather than from empty sections that only look finished.

This is a project note about the current KIT build, not a claim that every planned feature is available.
