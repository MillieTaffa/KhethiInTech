Git · checkpoint unlocked

Save a change

git status
git add path/to/file
git commit -m "Describe the change"
git log --oneline

Check the status first so you know what is about to join the commit party.

Mini challenge

Which command shows changes that are staged and unstaged? git status. It is the software equivalent of checking your pockets before leaving.

Git · careful undo

Unstage without deleting

git restore --staged path/to/file

git diff --staged

git restore path/to/file

The last command discards local edits to that file. Run it only when that is what you want.

Mini challenge

Want to remove a file from the next commit but keep your edits? Use git restore --staged. Want to throw away edits too? Stop, read the command again, then make a backup if unsure.

Terminal · find your feet

Move around safely

pwd          # show current folder
ls           # list files
cd folder    # enter a folder
cd ..        # go up one level
mkdir notes  # make a folder

Commands vary by shell. Be extra careful with deletion commands and file paths.

Mini challenge

Where are you right now? pwd. What is inside this directory? ls. The terminal does not judge. It does remember the exact folder.

HTML · semantic structure

Give a page a spine

<main>
  <h1>Page title</h1>
  <p>A clear introduction.</p>
  <section aria-labelledby="next-title">
    <h2 id="next-title">Next step</h2>
  </section>
</main>

Use headings in order and semantic elements that describe the content.

Mini challenge

How many main landmarks should a page normally have? One visible <main> element. Give repeated navigation a <nav> with a useful label.

CSS · layout buddy

Flex for a row, grid for a board

.toolbar {
  display: flex;
  align-items: center;
  gap: 1rem;
}

.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(15rem, 1fr));
  gap: 1rem;
}

Flexbox is handy for one dimension. Grid is handy when rows and columns both matter.

Mini challenge

Need cards to wrap without a media query? auto-fit and minmax() are a useful pair. Resize the browser and see what happens.

JavaScript · little list magic

Filter, then map

const projects = [
  { name: 'SocialPulse', done: true },
  { name: 'SentinelScanner', done: false }
];

const finished = projects
  .filter(project => project.done)
  .map(project => project.name);

filter() keeps matching items. map() transforms each one into a new value.

Mini challenge

Change the condition to show unfinished projects, then turn the result into project names. Hint: flip project.done.

Python · tidy data

Count things with a dictionary

scores = [8, 10, 8, 6]
counts = {}

for score in scores:
    counts[score] = counts.get(score, 0) + 1

print(counts)

A dictionary stores key and value pairs. Here each score is a key and its frequency is the value.

Mini challenge

What will the output be? {8: 2, 10: 1, 6: 1}. Add another score and run the loop again.

SQL · ask a better question

Filter, group and count

SELECT category, COUNT(*) AS total
FROM opportunities
WHERE is_open = TRUE
GROUP BY category
ORDER BY total DESC;

Read it in chunks: choose columns, choose a table, filter rows, group results and sort.

Mini challenge

Want the number of open opportunities in each category? This query does that. Want only categories with at least three? Add HAVING COUNT(*) >= 3.

HTTP · web conversations

Common methods and status codes

  • GET: read a resource
  • POST: submit or create data
  • PUT: replace a resource
  • PATCH: change part of a resource
  • DELETE: remove a resource
  • 200: okay · 404: not found · 500: server error

Actual behavior depends on the API. Read its documentation and never send secrets in a URL.

Mini challenge

Your API returns 404. Did the server crash? Not necessarily. It usually means the requested route or resource was not found. Check the URL and the API documentation first.

Security · safer defaults

Before you share a project

  • Remove passwords, tokens and private keys from the code.
  • Do not upload another person's personal information.
  • Use sample data and state where it came from.
  • Test only systems you own or have permission to assess.
  • Explain limitations and how to reproduce the result.

Security is mostly good habits repeated until they become boring. Boring is excellent here.

Mini challenge

You accidentally committed a private API key. Deleting it in a later commit may not remove it from history. Revoke or rotate the secret first, then follow the provider's cleanup guidance.
