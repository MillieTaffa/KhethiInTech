Git basics

Save a change

git status
git add path/to/file
git commit -m "Describe the change"
git log --oneline

Terminal

Move around safely

pwd          # show current folder
ls           # list files
cd folder    # enter a folder
cd ..        # go up one level

Commands vary by shell and operating system. Read a command before running it.
