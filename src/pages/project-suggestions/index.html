Build · practise · show your work

Project ideas for your portfolio.

Pick a small project, follow a video to get moving, then add your own twist. The useful part is not copying the finished screen. It is explaining what you changed, what broke and how you fixed it.

The videos are free to watch on YouTube. Some cloud services or optional tools may charge money. Check pricing, set a budget and delete resources you no longer need.

Software and web development

Your own portfolio site

Build a responsive homepage, about section, project cards and contact links. Add a real project only when it is yours, and make the page work with a keyboard.

  • Start with the video, then change the colours, content and layout.
  • Add mobile navigation, accessible labels and a short case study.
  • Publish a README with your design choices and next steps.

Frontend development

A study planner that forgives you

Create a weekly planner where tasks can be added, marked done and saved locally. It should be a helpful planner, not a tiny digital headteacher.

  • Follow a React introduction for components and state.
  • Add filters for today, this week and done.
  • Show an encouraging empty state and a reset button.
Follow the React course on YouTube ↗

freeCodeCamp.org · React course for beginners

Data and analytics

A tiny data story

Choose a public dataset, ask one good question, clean the data and make a chart that answers it. Keep the raw file and explain your choices.

  • Follow along with Python and pandas.
  • Compare a baseline with one interesting cut of the data.
  • Add a chart caption that includes a limitation or caveat.
Follow the pandas project course on YouTube ↗

freeCodeCamp.org · Pandas and Python for Data Analysis

FinTech and application development

Budget Buddy with fictional data

Create a simple budget tracker with categories, totals and a clear warning when a sample budget is exceeded. Use made-up values. Do not collect bank logins, card numbers or real financial details.

  • Follow the React introduction to learn components and state.
  • Add a form, validation and a readable summary.
  • Explain how you would protect private data in a production system.
Follow the React course on YouTube ↗

freeCodeCamp.org · Use the tutorial's building blocks and design your own budgeting project.

Cybersecurity · safe lab only

A suspicious link explainer

Build a local tool that flags common URL warning signs and explains them in plain language. This is an educational helper, not a verdict that a website is safe or unsafe.

  • Use a hand-written set of sample URLs. Do not probe real targets.
  • Show each rule and its limits, and avoid collecting visitor data.
  • Add harmless tests for the sample cases.

Cloud and DevOps

Deploy a small site, then shut it down

Take a static project and practise publishing it to a cloud host. Write down the steps, access rules and how to remove the resources afterwards.

  • First publish on a free static host if available.
  • Try a cloud tutorial only after reviewing its current prices.
  • Add a simple deployment checklist and a cost note to the README.
Follow the AWS deployment walkthrough ↗

A freeCodeCamp tutorial. Cloud services can create charges; use a budget alert and clean up after the exercise.

Systems analysis and APIs

A community resource directory

Map a small real-world need, such as finding study spaces or food gardens, then design a searchable directory. Begin with static data; add an API only when you understand why.

  • Ask a community member what information is useful.
  • Make the search accessible and clear when there are no matches.
  • Protect personal information and link back to original sources.
